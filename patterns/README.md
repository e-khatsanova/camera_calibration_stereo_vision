# Calibration patterns

В проекте используются четыре типа калибровочных мишеней,
поддерживаемых OpenCV:

- Chessboard
- ChArUco
- Symmetric Circles Grid
- Asymmetric Circles Grid

Готовые шаблоны мишеней хранятся в директории *generated/*.

ChArUco-паттерн генерируется средствами OpenCV с использованием
*cv2.aruco.CharucoBoard*.

Для Chessboard и Circles Grid используются заранее подготовленные
векторные шаблоны с известными геометрическими параметрами.

Каждая мишень будет исследована в двух вариантах:
- отображение на экране планшета;
- печать на бумаге.

Перед проведением калибровки физические размеры элементов мишени
проверяются измерением.
